Subir imágenes de vehículos en Flutter: navegador y móvil

Continuación de la creación del objeto Vehículo, el formulario y el CRUD. El objetivo es poder escoger una fotografía, visualizarla, guardarla en memoria junto al vehículo, editarla y eliminarla.

1. Revisar el punto de partida

El archivo lib/models/vehiculo.dart de actividad2a inicialmente solo tiene nombre y disponible. No tiene id, marca ni precio. No añadas estos atributos por accidente al copiar ejercicios de otras etapas; se explicarán por separado cuando se amplíe el catálogo.

Antes de editar, crear un respaldo o guardar un commit del estado inicial.

2. Instalar la dependencia

flutter pub add image_picker

El paquete proporciona ImagePicker, ImageSource.gallery y XFile. Abre un selector de fotografías compatible con navegador, Android e iOS. En Windows, algunas compilaciones con plugins requieren activar el modo desarrollador para habilitar enlaces simbólicos.

models: estructura de los datos; services: conexión con el selector de imágenes; repositories: almacenamiento y operaciones CRUD; pages: pantallas; widgets: controles reutilizables. El método build no debería seleccionar archivos ni almacenar datos directamente.

4. Ampliar el objeto en lib/models/vehiculo.dart

import 'dart:typed_data';

class Vehiculo {
  const Vehiculo({
    required this.nombre,
    this.disponible = true,
    this.imagenBytes,
  });

  final String nombre;
  final bool disponible;
  final Uint8List? imagenBytes;
}

Uint8List representa bytes (los datos binarios de la fotografía); el signo ? permite que no haya imagen. required obliga a proporcionar nombre, mientras que disponible tiene un valor por defecto. En la implementación de clase se añadió también copyWith para actualizaciones sin mutar el objeto.

5. Crear lib/services/imagen_service.dart

import 'dart:typed_data';
import 'package:image_picker/image_picker.dart';

class ImagenService {
  final ImagePicker picker = ImagePicker();

  Future<Uint8List?> seleccionarImagen() async {
    final XFile? archivo = await picker.pickImage(
      source: ImageSource.gallery,
      imageQuality: 75,
      maxWidth: 1600,
    );
    if (archivo == null) return null;
    final bytes = await archivo.readAsBytes();
    if (bytes.isEmpty) {
      throw const FormatException('Imagen vacía');
    }
    if (bytes.length > 5 * 1024 * 1024) {
      throw const FormatException('La imagen supera 5 MB');
    }
    return bytes;
  }
}

Future indica una respuesta futura. async habilita operaciones asíncronas; await espera la selección o lectura sin bloquear toda la interfaz. XFile? puede ser nulo si el usuario cancela. readAsBytes funciona en navegador y móvil; no se usa File ni dart:io, que no son compatibles con Flutter web.

6. Crear lib/repositories/vehiculo_repository.dart

import '../models/vehiculo.dart';

class VehiculoRepository {
  final List<Vehiculo> _vehiculos = [];

  List<Vehiculo> listar() => List.unmodifiable(_vehiculos);

  void guardar(Vehiculo vehiculo, {int? indice}) {
    if (indice == null) {
      _vehiculos.add(vehiculo);
    } else {
      _vehiculos[indice] = vehiculo;
    }
  }

  void eliminar(int indice) {
    _vehiculos.removeAt(indice);
  }
}

El repositorio separa el almacenamiento del formulario. Por ahora los vehículos e imágenes permanecen solo en memoria. Recargar la web o cerrar la aplicación elimina los registros; más adelante la API podrá guardar las fotografías de forma persistente.

7. Conectar el servicio a la página

Dentro del State de la pantalla Tienda, antes de build, define:

final ImagenService _imagenService = ImagenService();
Uint8List? _imagenSeleccionada;
bool _seleccionando = false;

Y agrega el método:

Future<void> _seleccionarImagen() async {
  setState(() => _seleccionando = true);
  try {
    final bytes = await _imagenService.seleccionarImagen();
    if (!mounted) return;
    if (bytes != null) {
      setState(() => _imagenSeleccionada = bytes);
    }
  } catch (error) {
    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Error: $error')),
    );
  } finally {
    if (mounted) setState(() => _seleccionando = false);
  }
}

setState redibuja la pantalla; mounted verifica que la página siga abierta después de la selección; try/catch maneja fallas; finally restablece el botón aunque ocurra un error.

8. Añadir botón y vista previa al formulario

OutlinedButton.icon(
  onPressed: _seleccionando ? null : _seleccionarImagen,
  icon: const Icon(Icons.add_photo_alternate_outlined),
  label: const Text('Elegir imagen'),
),
if (_imagenSeleccionada != null)
  Image.memory(
    _imagenSeleccionada!,
    height: 100,
    width: 150,
    fit: BoxFit.cover,
  ),

OutlinedButton.icon muestra icono y texto; onPressed llama el servicio; Image.memory pinta bytes sin depender de una ruta física; BoxFit.cover ajusta el recorte visual. El operador ! se usa aquí después de comprobar que no es nula.

9. Guardar, editar y mostrar

Al presionar guardar, crea Vehiculo(nombre: nombre, imagenBytes: _imagenSeleccionada) y pásalo a VehiculoRepository.guardar. Al editar, recupera vehiculo.imagenBytes para que vuelva a mostrarse en el formulario. En cada ListTile del listado usa:

leading: vehiculo.imagenBytes == null
  ? const Icon(Icons.directions_car)
  : Image.memory(
      vehiculo.imagenBytes!,
      width: 64,
      height: 56,
      fit: BoxFit.cover,
    ),

Al borrar se retira el vehículo del repositorio y su imagen asociada. La implementación de actividad2a/lib/main.dart ya contiene estos pasos conectados.

Nota de seguridad: para subir imágenes al servidor realmente hay que construir un endpoint autenticado, comprobar permisos por rol, validar tamaño, tipo y contenido en el backend, y almacenar el archivo fuera de la memoria de la app. La previsualización y la selección no equivalen a una subida HTTP.
